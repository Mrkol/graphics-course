# Тесселляция травы

В этом задании вам предстоит добавить адаптивную тесселляцию травы, чтобы изменять детализацию геометрии в зависимости от расстояния до камеры.

## Перед началом

Используйте решение предыдущего задания с процедурной травой. Размещение травинок, инстансинг и освещение уже реализованы, менять их не требуется.

## Задание

#### Шаг 1

Замените геометрию травинки на один треугольник: две вершины у основания и одна на верхушке.

Добавьте *Tessellation Control Shader* и *Tessellation Evaluation Shader*.

В Tessellation Evaluation Shader вычисляйте положение новых вершин с помощью барицентрической интерполяции.

#### Шаг 2

Реализуйте адаптивную тесселляцию: вблизи камеры травинки должны состоять из большого количества треугольников, а вдали — из минимального.

Перенесите вычисление изгиба травинок под действием ветра в Tessellation Evaluation Shader. Применяйте смещение после интерполяции, чтобы дополнительные вершины позволяли получить плавный изгиб поверхности.

Сохраните существующие параметры ветра и освещение травы.

#### Шаг 3

Добавьте в ImGui управление уровнем тесселляции и расстоянием, на котором детализация начинает уменьшаться.

Сравните производительность новой реализации с предыдущей, использующей фиксированное количество сегментов.
