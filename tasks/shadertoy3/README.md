# Shadertoy 3

Заключительная задача на Shadertoy. Продолжаем работу над вашим шейдером из задания [shadertoy 2](/tasks/shadertoy2/).

## Перед началом

 1. Создайте **новый** шейдер на [shadertoy](https://www.shadertoy.com/) и скопируйте в него код из задания [shadertoy 2](/tasks/shadertoy2/).
 2. Вспомните материал лекции про PBR.
## Задание

 1. Cгенерируйте новым вспомогательным шейдером процедурную текстуру, содержащую параметры roughness и metallness.
 2. Перепешите модель освещения на PBR.
 3. Используйте процедурные текстуры в качестве параметров для вашего PBR.
#### Заметка

Делать пулл-реквест для этой задачи не нужно, достаточно прислать ссылку на ваш шейдер-той.
