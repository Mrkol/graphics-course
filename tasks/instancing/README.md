# Инстансинг камней

В этом задании вам предстоит добавить на террейн множество камней и познакомиться с *инстансингом* (instanced rendering), позволяющим эффективно рисовать большое количество копий одной модели.

## Перед началом

Используйте решение предыдущего задания по террейну.

## Задание

#### Шаг 1

Загрузите две 3D-модели камней с Poly Haven:

- [Boulder 01](https://polyhaven.com/a/boulder_01)
- [Rock 09](https://polyhaven.com/a/rock_09)

Используйте формат glTF. Загрузите геометрию моделей в вершинный и индексный буферы.

Реализуйте инстансинг: вместо отдельного draw call для каждого камня храните матрицы преобразования экземпляров в `Storage Buffer` и обращайтесь к ним в вершинном шейдере через `gl_InstanceIndex`.

Все экземпляры одной модели должны рисоваться одним вызовом `vkCmdDrawIndexed`.

#### Шаг 2

Реализуйте процедурное размещение камней на поверхности террейна. Высоту расположения определяйте по карте высот.

Камни должны распределяться случайным образом, но воспроизводимо, без изменения положения при движении камеры. Используйте случайные повороты, масштабы и небольшие вариации цвета, чтобы избежать очевидных повторений.

Плотность размещения должна зависеть от высоты ландшафта. Например, камней должно быть меньше на пляжах и заснеженных вершинах.

#### Шаг 3

Нет смысла рисовать все камни острова, если большая часть из них не видна.

Генерируйте экземпляры только в окрестности камеры. Добавьте отсечение по расстоянию и пирамиде видимости (*frustum culling*).

Группируйте видимые экземпляры по моделям и загружайте их данные в GPU-буфер. Не забывайте про синхронизацию CPU и GPU при обновлении буферов.

Реализуйте PBR-освещение камней и добавьте в ImGui управление плотностью, дальностью отрисовки и диапазоном размеров.

## Бонусный уровень

В предложенном решении отбор видимых камней выполняется на CPU. Попробуйте перенести генерацию и отсечение экземпляров на GPU с помощью compute shader.

Для записи видимых экземпляров в общий буфер используйте **атомарный счётчик**: каждый поток должен атомарно увеличивать его, получая уникальный индекс для записи следующего экземпляра.

Используйте *indirect rendering*, чтобы GPU самостоятельно определял количество отрисовываемых экземпляров без передачи результата обратно на CPU.

Сравните производительность обоих подходов при разном количестве камней.
