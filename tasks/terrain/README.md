# Террейн

В этом задании вам предстоит создать процедурный ландшафт и научиться работать с картами высот, текстурированием и PBR-освещением.

## Перед началом

Скопируйте в эту папку любой работающий семпл, например [model_bakery](/tasks/model_bakery/). Не забудьте поменять название таргета в CMake.

## Задание

#### Шаг 1

Сгенерируйте карту высот 1024×1024 в формате `R32_SFLOAT`, используя многооктавный шум (fBm). Добавьте радиальную маску, чтобы получить остров с береговой линией.

Реализуйте управление параметрами шума через ImGui с возможностью перегенерации ландшафта.

#### Шаг 2

Создайте регулярную сетку из треугольников размером 256×256 ячеек. В вершинном шейдере семплируйте карту высот и смещайте вершины по вертикали.

Во фрагментном шейдере восстановите нормали поверхности по соседним значениям карты высот.

Добавьте свободную камеру для исследования ландшафта.

#### Шаг 3

Реализуйте четыре типа поверхности: песок, траву, камень и снег. Материалы должны плавно смешиваться в зависимости от высоты.

Используйте PBR-текстуры `Albedo`, `Roughness` и `Height`. Последние должны добавлять мелкие детали к нормалям без изменения геометрии.

Добавьте управление освещением и детализацией материалов через ImGui.
