# Трава

В этом задании вам предстоит добавить на террейн процедурно генерируемую траву, научиться размещать большое количество объектов на GPU и анимировать их под действием ветра.

## Перед началом

Используйте решение предыдущих заданий с террейном, инстансингом и отложенным освещением.

## Задание

#### Шаг 1

Создайте геометрию одной травинки в виде узкой полосы из нескольких треугольников. Разбейте её по высоте на несколько сегментов, чтобы травинка могла изгибаться.

Реализуйте отрисовку травинок при помощи инстансинга. Для каждого экземпляра храните положение, высоту, ширину, направление и небольшую вариацию цвета.

Используйте существующее PBR-освещение. Трава должна записывать свои параметры материала в G-буфер.

#### Шаг 2

Реализуйте процедурное размещение травы на GPU с помощью compute shader.

Разбейте поверхность на регулярную сетку ячеек. Для каждой ячейки генерируйте случайное положение травинки, используя хеш от координат ячейки. Размещение должно быть воспроизводимым при движении камеры.

Определяйте высоту травинки по карте высот террейна. Учитывайте тип поверхности: трава должна расти преимущественно в травяном биоме, а не на песке, камнях или снегу.

Дополнительно используйте [маску размещения травы](https://polyhaven.com/a/sparse_grass), чтобы распределение выглядело естественнее.

#### Шаг 3

Генерируйте траву только в ограниченном радиусе вокруг камеры. Реализуйте отсечение по расстоянию и пирамиде видимости (*frustum culling*).

Сохраняйте видимые экземпляры в `Storage Buffer`. Используйте атомарную операцию `atomicAdd`, чтобы каждый поток получал уникальный индекс для записи следующей травинки.

Количество экземпляров передавайте в команду отрисовки на GPU. Рисуйте всю траву одним вызовом `vkCmdDrawIndexedIndirect`, без чтения количества экземпляров на CPU.

Добавьте плавное уменьшение плотности травы с расстоянием, чтобы избежать резкого появления и исчезновения травинок.

#### Шаг 4

Добавьте анимацию травы под действием ветра.

В вершинном шейдере смещайте вершины травинок в направлении ветра с помощью периодических функций. Используйте координаты травинки и случайную фазу, чтобы избежать синхронного движения.

Основание травинки должно оставаться неподвижным, а верхняя часть — изгибаться сильнее.

Добавьте в ImGui управление плотностью, высотой и дальностью отрисовки травы, а также направлением, силой и скоростью ветра.
